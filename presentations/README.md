## 证据范围

原文配图与事实来自用户提供 arXiv:2603.03554v3；图表数据来自用户上传 s11 SLOT.csv。原文所引参考[19][20][21][25]的用途与书目信息由主文确认，未声称已读其全文。不存在新生成或伪造的HFSS场图。

**旧矩形地模型已在用户本机求解；新版有限GSG版图只完成二维连通性检查，尚未在HFSS中验证。本文档不是“图2d已精确复现”的结题报告。**
