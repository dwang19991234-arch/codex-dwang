# HFSS 近似复现：论文图 2d

**如果使用 HFSS 2021 R1，请改用 [内置脚本说明](../hfss_2021/README_2021R1.md)，不要执行本文件中的 PyAEDT 安装与运行命令。**

这是按显微图估计版图的 **HFSS 参数化建模脚本**，不是已求解的 `.aedt` 工程，也不是作者原始模型。云端没有 AEDT/HFSS 或许可证，因此尚未验证 AEDT 内建模、网格或求解。已完成几何参数检查、共享几何预览、Python 语法检查及 PyAEDT 0.18.1 源码接口核对。

## 1. 本地准备与运行

需要带 HFSS 许可证的 Ansys Electronics Desktop，以及独立 CPython 3.10–3.12（推荐 3.11）。脚本使用 PyAEDT，而不是 AEDT 内置 IronPython。接口按 PyAEDT 0.18.1 编写；其发布说明以 AEDT 2025 R1 为测试版本，其他 AEDT 版本需实际验证。

在本文件所在目录打开 PowerShell：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 不启动 HFSS：检查参数、画版图
.\.venv\Scripts\python.exe build_hfss.py --dry-run --output preview

# 启动 HFSS，只建模和保存，先检查几何、材料和端口
.\.venv\Scripts\python.exe build_hfss.py --aedt-version 2025.1 --output model_01

# 确认后：新建另一项目并求解；不要重复使用已存在项目的输出目录
.\.venv\Scripts\python.exe build_hfss.py --aedt-version 2025.1 --solve --cores 4 --output run_01

# 求解结束后绘制阻抗和 S11，并核对离散点
.\.venv\Scripts\python.exe plot_results.py run_01
```

把 `2025.1` 换成你的 AEDT 版本，例如 `2024.2`；也可省略 `--aedt-version`，让 PyAEDT 检测安装。默认打开独立 AEDT 会话，运行后保留 GUI。批处理可添加 `--headless`；批处理结束会关闭该会话并释放许可证。

`--cores 4` 不保证许可证支持四核；若出现 HPC 授权错误，先使用 `--cores 1`。脚本不会安装 HFSS 或提供许可证。

首次建模若报错，将终端完整错误及输出目录中的验证日志保留；不要把失败模型当作有效结果。脚本拒绝覆盖已有 `.aedt` 项目，继续尝试请换输出目录。

## 2. 文件与输出

- `parameters.json`：初始尺寸；长度统一为 μm，电导率 S/m，电阻 Ω。
- `build_hfss.py`：参数化几何、PEC、硅材料、集总端口、开放边界、网格及扫频。
- `plot_results.py`：只读取真实 HFSS 导出的 CSV，绘制双纵轴阻抗和 S11。
- `output/layout.png`：已生成的几何预览，不是仿真场图。
- 本地运行后的 `graphene_double_slot.aedt`：实际 HFSS 工程。
- `validation.json`：HFSS 本地模型检查，尚未在云端生成。
- `Sweep100_220.csv`、`CheckDiscrete.csv`、`convergence.txt`：求解后导出；云端没有这些结果。
- `fig2d_approx.png/.pdf`：本地求解并执行绘图脚本后生成。

## 3. 依据与估计值

正文已知：约 1 kΩ 石墨烯、100 Ω·cm 硅、300 nm SiO2、3 nm Cr / 80 nm Au、部分低阻抗段 6 μm 缝隙。频率 100–220 GHz；130 GHz 是参考工作频率。

从图 1a 的 500 μm 标尺粗估，初始化为：

| 参数 | 初值（μm） | 来源 |
|---|---:|---|
| 槽总长 `slot_L` | 260 | 图像估计 |
| 槽宽 `slot_W` | 12 | 图像估计，边缘分辨率较低 |
| 两槽中心距 `slot_D` | 125 | 图像估计 |
| 中心导体宽 `feed_W` | 12 | 图像估计 |
| 探测器间隙 `det_gap` | 6 | 建模假设，不是论文给出的石墨烯沟道长度 |
| 高低阻抗段各段长度 `choke_L` | 120 | 图像估计，共 10 段 |
| 低阻抗宽段宽 `low_W` | 110 | 图像估计 |
| 高阻抗窄段宽 `high_W` | 12 | 图像估计 |
| 宽段对地间隙 `gap` | 6 | 正文给出的低阻抗段缝隙 |
| 渐变段长度 `taper_L` | 130 | 图像估计 |

硅 εr=11.7 为常见初值假设，σ=1 S/m 由正文电阻率换算。初版材料不含频率色散。

正文描述槽长 λ/2、探测器到槽距离 λ/4。这里的照片估计与以简单 εeff 公式推导的尺寸并不完全一致，不能假定两者等价。初版优先保留照片轮廓；这些估计尚不能保证在 130 GHz 谐振。

## 4. 当前简化与端口含义

- 金属为零厚度 PEC；未加入 80 nm Au / 3 nm Cr 的有限电导损耗。
- 未显式加入 300 nm SiO2、hBN、微米齿形及石墨烯色散。
- 硅沿横向延伸至计算边界，向下延伸 1000 μm；外表面使用辐射边界，近似硅半空间。它不是有限厚硅片，也不是实体硅球透镜。边界反射需要检查。
- 芯片上金属外轮廓简化为矩形，未保留测量焊盘与整个封装。
- 左端 IF 导线采用开路；没有假定一个未经论文确认的 50 Ω 终端。要验证 IF 负载影响，需要另建带实际负载的模型。
- 石墨烯处使用 **1000 Ω 参考的集总端口**，提取天线匹配；没有额外并联电阻。这里未计算石墨烯实际吸收、光热电流或探测响应率。

若原图 S11 的端口参考阻抗不是 1000 Ω，黑线会不一致。论文图注未给出足够信息，不能单凭负载电阻确定作者的 S11 归一化。CSV 的输入阻抗根据同一端口的 S 参数反算：

`Zin = 1000 * (1 + S11) / (1 - S11)`

`accepted_fraction_1port = 1 - |S11|²` 是净接受功率比例，**不是辐射效率或石墨烯吸收率**。

## 5. HFSS 中需要人工检查的项目

1. 确认只有一个 Graphene 集总端口，积分线跨过中心间隙并接触两端 PEC。左侧馈线不应与地短接，右侧馈线应与右侧地连通。
2. 查看 Modeler 中的各层和 Boolean 历史；确认导体间隙、双槽、扼流段符合 `layout.png`。端口片保持独立，不能被设为 PEC。
3. 开放边界应只在上下两个计算域的十个外表面，不能出现在内部 z=0 硅/空气界面。
4. 自适应频率为 100、130、220 GHz，ΔS≤0.02，最多 15 次、至少 3 次及连续 2 次满足收敛。达到最大次数不代表收敛。
5. 主扫描为 100–220 GHz，0.5 GHz 输出间隔的插值扫描；另有 100、110…220 GHz 共 13 点离散扫描。输出间隔不是求解精度；窄峰附近需要更密集离散扫描。
6. 查看 `convergence.txt` 与 HFSS 收敛曲线；再将金属网格 12→8 μm、端口 2→1 μm，并收紧 ΔS 至 0.01。建议谐振位置变化 <1%、主要阻抗特征变化 <5%。
7. 将 `margin`、`air_H`、`si_H` 分别扩大约 50%，检查开放边界影响；有条件时使用合适的 PML 对比。
8. 同一频率上核对复数 S11 的插值/离散差异，绘图脚本用 0.02 作为初步报警阈值。必须同时检查实部/虚部及被动性，不能只看黑线最低点。

## 6. 参数调整顺序

先改 `parameters.json` 并用新的输出目录重建。优先扫描 `slot_L`、`slot_D`，再检查扼流段 `choke_L` 与窄/宽导体宽度，最后细化 `det_gap` 和馈点寄生。修改槽长会影响槽谐振，槽间距和扼流段也会改变端口变换；不要假定所有变化都符合单一 λ/4 公式。

几何变量保存在 AEDT 中，支持手动改变；积分线已参数化。材料 εr、σ 和部分求解/网格设置由构建脚本赋值，修改这些参数请重新构建。图像尺寸存在不确定性，参数扫描应记录每次修改，不能仅以贴合原曲线作为唯一正确性判据。

建议第一轮先运行初始模型，把 `Sweep100_220.csv`、`CheckDiscrete.csv`、`convergence.txt` 和参数文件一起带回，以实际曲线确定后续尺寸调整，而不是预先伪造与论文重合的结果。
